Tips for a better gift list

  • Set the budget for each person before you start shopping, then add them up and compare with your total.
  • Write the idea next to the name the moment you think of it. Overheard hints are your best source.
  • Use "Actual" to log what you really paid. If it runs over, trim the next person on the list instead of ignoring it.
  • Buy for far-away relatives first so postage is not rushed.
